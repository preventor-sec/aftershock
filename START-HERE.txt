AFTERSHOCK — START HERE
Zero-dependency public-surface checker. Passive, bounded, honest.

1) NO INSTALL, JUST LOOK
   Live page: https://preventor-sec.github.io/aftershock/
   Open aftershock.html in any browser. The example report, advisory
   snapshot and evidence analyzer work from the file alone.

2) LIVE SCANS FROM THE SINGLE FILE
   Click "Get the local reader" in the page, save aftershock-reader.mjs,
   then run:  node aftershock-reader.mjs
   It prints a one-time pairing code; paste it into the page when asked.
   The reader listens on 127.0.0.1 only — websites cannot borrow it.
   The SHA-256 of the reader appears in the page; verify it before trusting.

3) FULL REPOSITORY MODE
   npm start   → http://127.0.0.1:4175  (same scanner, no pairing needed)
   npm test    → 43 tests

Only scan websites you own or have permission to assess.
Evidence first. Uncertainty included.
