# Changelog

## 0.4.2 — 22 October 2026

### The single-file artifact can now scan live sites
- Added `aftershock.html`: the entire app in one file — UI, evidence analyzer,
  advisory snapshot, and an embedded copy of the reader, downloadable with one
  click (SHA-256 shown in the page).
- Added `reader.mjs` (repository form) and `aftershock-reader.mjs` (single-file
  form generated by `tools/build-reader.mjs`): a zero-install local companion.
  Browsers hide one site's response headers from another page (CORS), so no
  HTML file can scan alone; the reader runs the repository's exact bounded
  passive scanner on loopback (127.0.0.1:4176-4180), gated by a one-time
  pairing code printed at startup.
- Reader safety: loopback-only binding, Host pinning, pairing code required on
  every request, 5 invalid attempts stop the process, per-host rate limits,
  2 KiB body cap, one scan at a time. No logs, no telemetry, no accounts.
- `app.js` now discovers the reader automatically (ports 4176-4180) when the
  repository server is unavailable; pairing survives the browser session via
  sessionStorage. `tests/` remain green (43/43).
- New hero action: "Get the local reader ↓" beside the example and scope links.
