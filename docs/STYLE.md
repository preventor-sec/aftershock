# Inspected visual direction

User selected: **black, minimal Grok Bot style**.

The live grok.bot redirect reaches x.ai/bot but its Cloudflare page blocked automated inspection. Two publicly published site screenshots were rendered and visually inspected on 2026-10-22. The selected dark hero shows a near-black canvas, centered white headline, generous negative space, a compact announcement pill, white primary pill button and subdued secondary button. The other screenshot showed a white feature-page variant; the user explicitly chose the dark direction.

Reference image sources:
- https://imagedelivery.net/ucJpyG2KeBV3j55SXwy6sQ/aicrier/post/a8c6c871-1d1a-41fd-a1d7-f7a09bcf9b25/public
- https://www.uuaihub.com/screenshots/grok-bot-site-teammate.png

Aftershock applies the dark composition with its own compass/orbit mark, content, evidence interactions and product structure. It uses system fonts, rounded controls, subtle graphite borders and restrained amber for unresolved findings. No third-party logos, mascot assets, screenshot assets or proprietary fonts are packaged. This is reference-based design, not a pixel-exact copy.
