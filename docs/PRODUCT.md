# Product contract

Aftershock shortens the response loop: URL → observed public evidence → focused fix brief → fresh response comparison.

The user rejected an upload-first prototype and a light dashboard. The current journey requires only a public URL, accepts bare domains, performs actual backend requests and preserves a black minimal visual style.

A quick scan should answer: what was observed, why it matters, what to change, what was not established, and what changed after the next deployment. The tool must not report a hidden PHP/Node runtime as safe. UI priorities are clarity, immediate usefulness, understandable failure states and evidence the next coding agent can act on.

No global security score, fabricated progress percentage, invented agent census or fake CVE confirmation. Scanner priority describes what to review first, not a formal severity rating. The advisory cards are context, not proof that the submitted website uses those technologies.

Current scope and extensions are in ORBOFI-HANDOFF.md and ARCHITECTURE.md. Source/dependency connectors may be added later as optional depth, never as a prerequisite to the URL flow.
